Entry for the [Funniest Time Machine Warning Label](https://make.fun/competitions/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty on make.fun.

`main.ts` writes a single warning label (89 characters, one line) to `/output/entry.txt`:

> WARNING: If you meet yourself in the past, do not lend him money — he never pays it back.

Run it with Node 22+: `node main.ts`. Offline and deterministic — no network, no API calls, no randomness. A runtime guard enforces the 1–120 non-blank character gate.
